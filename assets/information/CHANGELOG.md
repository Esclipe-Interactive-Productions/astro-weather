# Changelog

## Version History

### Version Format
All versions will now be in this new format. Major, minor, build number, (revision, iteration, patch). This is optional for .md or informational files.

As an example:

    1.3.18-r1
  
  1 = Major
  
  3 = Minor
  
  18 = Build Number
  
  r1 = Revision #1
